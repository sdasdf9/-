Курс «Полный стек веб-разработчика»

Данный курс предназначен для начинающих разработчиков, желающих освоить профессию Full Stack. Программа охватывает как фронтенд, так и бэкенд технологии.

1. Фронтенд разработка

Фронтенд — это клиентская часть веб-приложений, отвечающая за отображение и взаимодействие с пользователем.

1.1 Основы HTML и CSS

В этом разделе вы изучите структуру веб-страниц с помощью HTML и научитесь стилизовать их с использованием CSS.

1.2 JavaScript и взаимодействие с DOM

JavaScript позволяет делать страницы интерактивными: обрабатывать события, изменять содержимое на лету и работать с DOM-деревом.

1.3 Современные фреймворки (React/Vue)

Изучение популярных JavaScript-фреймворков ускорит разработку сложных пользовательских интерфейсов.

1.3.1 Введение в React: компоненты и состояние

React использует компонентный подход и виртуальный DOM для эффективного обновления интерфейса.

2. Бэкенд разработка

Бэкенд — это серверная часть приложения, обрабатывающая запросы, данные и бизнес-логику.

2.1 Введение в Python и Django

Python — один из самых популярных языков для бэкенда, а Django — мощный фреймворк для быстрого создания веб-приложений.

2.2 Работа с базами данных (PostgreSQL)

В этом разделе вы научитесь проектировать базы данных, писать SQL-запросы и интегрировать их с Django моделями.

2.3 API и архитектура REST

REST API позволяет фронтенду и бэкенду обмениваться данными через HTTP-запросы в формате JSON.

2.3.1 Аутентификация и авторизация в API

Безопасность веб-приложений: JWT-токены, сессии и права доступа пользователей.

3. DevOps и деплой проектов

Развёртывание приложений на серверах — финальный этап разработки, требующий знания инструментов DevOps.

3.1 Docker и контейнеризация

Docker позволяет упаковывать приложения в контейнеры, обеспечивая одинаковое окружение на всех этапах разработки.

3.2 Облачные сервисы (AWS/Heroku)

Размещение готовых проектов в облаке делает их доступными для пользователей из любой точки мира.

3.2.1 CI/CD пайплайны и автоматическое тестирование

Непрерывная интеграция и доставка автоматизируют тестирование и развёртывание кода при каждом изменении.
